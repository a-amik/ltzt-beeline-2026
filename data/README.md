# Датасеты

Шесть CSV из ТЗ (`;`-разделитель, UTF-8): заявки и контроль по трём
участкам — «Восток», «Юго-Восток», «Юго-Центр». Данные задания
конфиденциальны (п. 7.3.4—7.3.5 положения конкурса), поэтому в открытом
репозитории вместо них лежит **обезличенный набор того же вида**:

- заявки, окна, типы BK и HD, районы, статусы и контрольное распределение
  по бригадам — как в файлах задания;
- каждый адрес заменён настоящим жилым домом в 120—350 м от исходного,
  в том же городе (обратный геокодер Nominatim, © OpenStreetMap contributors);
- номера заявок и квартир — новые случайные, фамилии бригад — вымышленные.

Всё, что собрано из CSV, — наборы, геокоды, матрицы, имитации — собрано
заново из обезличенного набора теми же командами, и прототип поднимается
на нём без сети. Работу на данных задания команда показывает на стенде
за входом. Числа в отчётах (`benchmark/`, `race/`, `generalize/`)
посчитаны на данных задания; на обезличенном наборе они близки, но
не совпадают до единицы. Чтобы пересобрать наборы из своих CSV, положите их
в `raw/` под именами `<участок>-zayavki.csv` и `<участок>-kontrol.csv`.

## Что здесь собирается

| папка | чем сделана |
|---|---|
| `raw/` | CSV в формате ТЗ; в открытом репозитории — обезличенный набор |
| `datasets/` | `python -m bee_routing.prepare` — датасеты по контракту |
| `matrices/` | `python -m bee_routing.matrices` — матрицы OSRM, четыре профиля |
| `datasets/moskva.json`, `matrices/moskva-*` | `python -m bee_routing.moscow` — «Вся Москва»: три участка одним набором, у бригады свой офис, выезд в чужой участок стоит `economy.sector_cross_rub` |
| `frontend/public/geo/moscow-districts.geojson` | `tools/geo/moscow_districts.py` — границы всех районов Москвы и застройка Каширы, Ступина, Домодедова для карты «Нагрузки» (© OpenStreetMap contributors, ODbL) |
| `samples/moskva-sintetika.csv` | `tools/synthetic/moscow_csv.py` — синтетический день по Москве для загрузки с экрана: районы задания, дома из OSM, факт по бригадам |
| `geocode.json` | кэш Nominatim: повторная подготовка в сеть не ходит |
| `assumptions.json` | все допущения прототипа; в коде чисел нет |

Собранное лежит в git нарочно: API поднимается без сети, без OSRM
и без шага подготовки. Поля, единицы и правила восстановления словами —
в [документации](https://nami.amik.am/app/s/6118d05a96d7cf23ee93528c44bf11aa),
раздел 5.
